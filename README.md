# Trabalho 1 - Introdução à Computação no Mercado Financeiro

Projeto desenvolvido para a disciplina **SSC0964 – Introdução à Computação no Mercado Financeiro**, da Universidade de São Paulo (USP).

## Objetivo

O objetivo deste trabalho é desenvolver modelos para seleção e análise de carteiras de investimentos utilizando Python, aplicando métricas de desempenho e conceitos de mercado financeiro.

## Tecnologias utilizadas

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Statsmodels

## Arquivos

- `ssc096_trabalho1.ipynb` – Notebook contendo toda a implementação e análise dos resultados.

## Conteúdo

O projeto inclui:

- Importação e tratamento dos dados;
- Construção dos modelos de seleção de ativos;
- Cálculo de métricas como:
  - Retorno anualizado;
  - Volatilidade;
  - Índice Retorno/Volatilidade;
  - Drawdown;
  - Alpha;
  - Beta;
- Geração de gráficos para comparação dos modelos.
